## 2. 需求理解

- 工程目录 `061 camber esp32` → 赛车外倾角测量工具
- **外倾角** = 轮平面与铅垂面的夹角，绕车体纵轴旋转
- 传感器 X 轴对准轮轴/车长方向时，**X 轴倾角 θ = atan2(ay, az)** 即外倾角
- 典型量程 ±5°，分辨率需求 0.01°，静态精度优于 0.1°
- 工况含发动机振动与路谱振动 → 抗振是核心指标（普通 atan2 解角在振动下偏差可达数度）

## 3. 硬件方案

直接采用 ESP32-C6-Touch-AMOLED-2.16 开发板作为传感器本体：

| 模块 | 选型 | 理由 |
| --- | --- | --- |
| MCU | ESP32-C6 | 板载，单核 RISC-V，足够算力 |
| IMU | QMI8658（板载） | ±2g 分辨率 1/16384 g，满足 0.01° 需求（1/16384 g ≈ 0.0035°） |
| 显示 | 480×480 AMOLED 触摸 | 大字号角度读数 + 触摸校准按钮，AMOLED 户外可视性好 |
| 电源 | AXP2101 + 锂电 | 板载充电管理，便携 |

QMI8658 配置：加速度 ±2g / 500Hz，陀螺 ±256dps / 500Hz（小量程换取分辨率）。

## 4. 算法方案

### 4.1 角度定义

```
θ_x = atan2(ay, az)     （单位：度）
```

水平静止（ay≈0, az≈+1g）→ 0°；+Y 向下倾斜 → 正角。

### 4.2 振动误差根因

逐拍 `atan2(ay, az)` 在周期线加速度（振动）下存在**系统性偏差**：atan2 非线性，
振动正负半周的角度偏差不对称，滤波后残留数度误差（验证脚本复现：0.3g 振动偏差 6°）。
因此不能只靠调滤波参数解决。

### 4.3 解决：窗口矢量平均 + 互补滤波 + 自适应门限

1. **矢量域滑动平均**（128 拍 / 256 ms）：先平均 (ax, ay, az) 再解 atan2。
   零均值周期振动在矢量域相互抵消，从根本上消除凸性偏差。
2. **互补滤波**（α=0.99）：陀螺 X 轴积分桥接动态（含零偏标定，实测零偏约 +5dps），
   加速度计提供长期基准。
3. **置信度门限**：平均矢量模长偏离 1g（振动/线加速度）或新息（角度偏差）过大时
   自动切到陀螺主导，防止加速/刹车工况污染读数。

### 4.4 数值验证（tools/verify_tilt.py）

| 用例 | 结果 |
| --- | --- |
| 静态精度 ±3.5° | 0.000° |
| 0→2° 阶跃收敛 | 1.06 s |
| 25Hz/0.3g 振动 | 0.012° |
| 多频振动 12/37/58Hz | 0.019° |
| +2g 干扰 0.4s 陀螺保持 | 0.052° |

## 5. 软件架构

```
sensor_task (500Hz 采样)
  ├── qmi8658_read_sensor_data()      QMI8658 驱动
  ├── tilt_update()                   窗口平均 + 互补滤波
  ├── printf CSV @50Hz                串口记录
  └── ui_camber_update() @25Hz        LVGL 界面（加锁）
LVGL 任务
  ├── 角度大字 / ±5° 刻度尺 / 峰值
  └── 按钮：归零(NVS) / 峰值复位 / 反向(NVS)
```

复用官方例程组件：pmicpower（AXP2101）、port_bsp（I2C/显示/触摸）、app_bsp（LVGL 移植），
自有代码：`components/tilt/`（算法）、`components/qmi8658/`（驱动，源自官方 Arduino 例程）、
`main/`（应用 + UI）。

## 6. 遗留事项

- 本机无 ESP-IDF 框架（仅工具链），固件需在装有 ESP-IDF v5.5.x 的环境编译烧录
- 上车后建议用角度块做三点标定，并验证磁吸座装夹重复性
- 后续可加 BLE 广播角度给上位机 / SD 卡记录（板载资源均已预留）
